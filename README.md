# Student Performance Analysis

This project analyzes the relationship between gaming habits and students' academic performance using data preprocessing, machine learning, and interactive data visualization. The project includes ETL processing, predictive modelling, and Power BI dashboards to generate meaningful insights from the dataset.

## Project Structure

```text
.
├── data_mining.ipynb                   # Machine learning model development and evaluation
├── etl.ipynb                           # Data extraction, transformation, and loading process
├── insight_testing.ipynb               # Exploratory analysis and insight generation
├── Gaming vs Academic Performance Dasboard.png # Dashboard Image Power BI
├── Gaming vs Academic Performance.pbix # Interactive Power BI dashboard
├── Gaming_Academic_Performance.csv     # Original dataset
├── Gaming_Academic_Performance_DM.csv  # Dataset prepared for data mining
├── Gaming_Academic_Performance_DW.csv  # Dataset formatted for data warehouse
├── Gaming_Academic_Performance_ETL.csv # Cleaned dataset after ETL process
├── insight_bar_genre_grades.png        # Average grades by gaming genre
├── insight_bar_stress_grades.png       # Average grades by stress level
├── insight_feature_importance.png      # Machine learning feature importance
├── insight_heatmap_correlation.png     # Correlation matrix visualization
├── insight_scatter_trendline.png       # Study hours vs grades trend analysis
├── Star Schema - Gaming vs Academic Performance.png # Star schema design for the data warehouse
└── README.md                          # Project documentation
```

## Dataset

**Gaming vs Academic Performance**

The dataset contains information about students' gaming habits, study hours, stress levels, attendance, sleep patterns, and academic performance.
